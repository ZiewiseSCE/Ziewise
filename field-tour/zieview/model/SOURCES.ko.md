# ZIEVIEW 3D 제품 모델

회사에서 지정한 **Zieview_지명원_Rev4.pptx**를 보고 신규 제작한 실물 비례 시각화다. 제품 사진이나 파노라마를 제품 표면에 투사하지 않는다. 앞뒤로 돌아볼 수 있는 함체, 광학부, 브래킷, 폴대, 자석 하드웨어는 모두 닫힌 입체 또는 두께가 있는 조립 부품으로 구현했다.

## 외형 근거

| 자료 | 반영한 내용 |
| --- | --- |

각 장착물의 외관은 제품을 설명하기 위한 시각화다. 자료가 공개한 외부 함체 치수를 기준으로 모델링했으며, 미공개 광학기 내부, 보이지 않는 체결부와 현장 I형강은 제조 CAD 또는 조립 도면의 측정치로 표기할 수 없다. 지명원에 표기된 최대 5m는 폴대 확장 가능 높이다. 화면 모델은 표지의 낮은 설치 상태를 보여 준다.

## 재질 파일

- **green-coating-normal.webp / green-coating-rough.webp** · Rev4 image32.jpeg의 로고·형상이 없는 녹색 코팅 작은 영역 두 곳에서 명도 고주파만 추출한 128×128 미세 표면 지도. 거칠기와 노멀 강도는 렌더에 맞추어 설정한 근삿값이다.
- **column-steel-normal.webp / column-steel-rough.webp** · 같은 회사 원본의 기둥 표면에서 추출한 128×128 미세 표면 지도. 원본 현장 전경과 제품 윤곽을 포함하지 않는다.
- 외부 모델·스톡 이미지·상용 폰트·제3자 PBR 지도에 의존하지 않는다. 사진의 회사 이름과 제품 형상은 회사 제공 자료의 브랜딩이다. 홈페이지에서 이 모델을 사용하기 위한 출처 기록이다.

## 통합

공개 폴더에 zieview.mjs와 mark.mjs, WebP 재질 네 개를 나란히 둔다. 모듈을 읽는 즉시 기본 재질의 메시가 생긴다. `ready`는 미세 표면 지도가 적용된 시점을 가리킨다.

```js
import { buildZieview } from './zieview.mjs';

const asset = buildZieview(THREE, {mount: 'magnet'});
scene.add(asset.group);
await asset.ready;
asset.update(0.4);
```

- 로컬 Y는 위, +Z는 함체 로고 면이다. 1 유닛은 1m이며 두 가지 형식 모두 바닥 y=0에 접한다.
- `group`은 현장 배치와 통합 궤도 회전용 루트다. `anchors`는 광학부, 녹색 함체, 장착부의 루트 로컬 좌표다. 별도 `targets.full`, `targets.head`, `targets.optic`, `targets.attachment`도 제공한다.
- `setAim(pan, tilt)`는 라디안 입력으로 광학부를 회전한다. `update(p)`는 0부터 1까지 짧은 PTZ 스캔을 실행한다. `setExploded(p)`는 자석형을 기둥에서 최대 0.185m 앞으로 분리한다. `pole.visible=false`로 뒤쪽의 3개 금속 자석 컵을 직접 볼 수 있다. `pole`은 삼각대형에서 null이다.
- 배칭 뒤 제품 지오메트리는 삼각대형 27개 메시·76,848개 삼각형, 자석/기둥형 25개 메시·78,706개 삼각형이다. HDR 환경 반사, sRGB 출력과 접지 그림자를 함께 사용하면 도장면, 금속 걸쇠, 광학창이 잘 구분된다.

| 범위 또는 구도 | 값 |
| --- | --- |
| 삼각대형 전체 외접 치수 | 약 W 0.681 × H 1.597 × D 0.723m |
| 자석형과 기둥을 합한 외접 치수 | 약 W 0.431 × H 1.763 × D 0.453m |
| 단말 원점 높이 H | 삼각대형 1.210m, 자석형 1.260m |
| 삼각대 전체 구도 | 카메라 [-0.67, 1.17, 2.43] → [-0.028, 0.79, 0], 수직 시야각 43° |
| 제품 3/4 구도 | [-0.38, H+0.268, 0.624] → [-0.056, H+0.176, 0.002], 38° |
| 광학부 접사 | [-0.207, H+0.343, 0.357] → [-0.159, H+0.302, 0.016], 38°. `setAim(-0.16,-0.021)` |
| 자석 체결부 뒷면 | 기둥 숨김. [0.396, H+0.166, -0.542] → [0, H+0.105, -0.052], 37° |

독립 WebGL 검수 결과는 작업 폴더 .qa/proof-contact.jpg와 .qa/validation.json에 있다. 브라우저에서 삼각대 전체, 앞·옆·뒤, 광학부·다리 접사와 자석 설치·측면·체결부 뒷면을 렌더했다.
