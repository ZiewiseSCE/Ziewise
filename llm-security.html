문서·질문·추론의 위치

문서 저장소, 임베딩 생성, 검색 색인, 모델 추론과 로그를 고객 인프라에 두는 로컬 전용 구성을 설계합니다. 인터넷이 제한된 현장은 모델 파일·업데이트·모니터링까지 내부에서 운영할 수 있는지 함께 점검합니다.

모델이 읽기 전에 권한 확인

사내 계정과 부서·직무 권한을 문서의 접근 목록에 연결합니다. 원가표를 읽을 수 없는 직원이 질문하면 해당 문단을 검색 후보에서 제외하고, 답변의 원문 링크를 열 때도 권한을 다시 확인합니다.

운영 데이터까지 고객이 관리

질문과 응답의 저장 여부, 민감 항목 가림 처리, 로그 열람자와 보관 기간을 정합니다. 전송·저장 암호화, 백업과 키 관리, 퇴직자 권한 회수 및 삭제 문서의 색인 반영도 운영 범위에 포함해 설계합니다.
